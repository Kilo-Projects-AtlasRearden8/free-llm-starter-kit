# Prompt Starters

Copy and paste these prompts into your local LLM. Fill in the bracketed parts with your own words. No account, no API key, no special formatting needed.

Tips: be specific, tell the model who you are, and say how long you want the answer. If the first reply is not quite right, reply with "Make it shorter" or "Give me an example" and try again.

## Everyday writing

**Write a short email**

```
Write a polite, short email to [person] about [topic]. Keep it to two paragraphs. Tone: friendly but professional.
```

**Turn notes into a clean message**

```
I am going to paste some rough notes. Turn them into a clear, well-organized message. Do not add facts that are not in my notes.

[Paste your notes here]
```

**Summarize a long article**

```
Summarize the following text in 3 bullet points. Keep it plain and accurate. Do not invent details.

[Paste article text here]
```

## Learning and explaining

**Explain like I'm new to this**

```
Explain [topic] like I have never heard of it before. Use everyday examples, no jargon unless you define it, and keep it under 200 words.
```

**Make a study plan**

```
I want to learn [topic] in [number] weeks. I have [hours per week] to study. Make me a simple week-by-week plan with one main goal per week.
```

**Quiz me**

```
Quiz me on [topic]. Ask one multiple-choice question at a time. Wait for my answer, tell me if I am right, then ask the next question.
```

## Admin and paperwork

**Draft a polite reply to a messy email**

```
Someone sent me this email: [paste email]. Draft a calm, professional reply that [what you want to say]. Do not share my personal details.
```

**Make a checklist**

```
I need to [task, e.g. move apartments / file taxes / start a small side project]. Make a step-by-step checklist, in plain language, with realistic time estimates.
```

**Rewrite for readability**

```
Rewrite the following text so a busy person can skim it in 30 seconds. Use short sentences and bullet points.

[Paste text here]
```

## Healthcare worker aids (education only, never medical advice)

These are for organizing and communicating information, not for diagnosis or treatment decisions. Never enter real patient names, dates of birth, medical record numbers, or any identifying health information.

**Prepare questions for a care team meeting**

```
I am a healthcare worker helping a patient and family prepare for a care team meeting. Draft a list of respectful, plain-English questions a family might ask about [condition or situation]. Keep it educational, not clinical.
```

**Write plain-English patient education notes (template only)**

```
Create a template for plain-English discharge education notes about [topic]. Include sections for: what happened, what to watch for, when to call, and follow-up. Mark clearly where a clinician must fill in patient-specific details. Add a disclaimer that this is education only, not medical advice.
```

**Shift handover wording**

```
Rewrite these rough shift notes into a clear, objective handover summary. Remove opinions and assumptions. Keep only observed facts and actions taken.

[Paste rough notes, no patient identifiers]
```

Never paste real patient data into any AI, local or otherwise. Local AI keeps data on your machine, but healthcare privacy rules still apply to how you handle information.

## Writing and creativity

**Book blurb (for authors)**

```
Write a 100-word book blurb for a [genre] novel about [premise]. Tone: warm and inviting. End with a hook that makes readers curious.
```

**Blog post outline**

```
Create a blog outline for [topic]. Audience: beginners. Include a title, introduction, 4–6 sections, and a conclusion. Keep the tone friendly and encouraging.
```

**Rewrite a difficult letter**

```
Rewrite this letter so it sounds calm and clear, not angry. Keep all the facts the same.

[Paste letter here]
```

## Fun

```
Explain the [name] chess opening in plain language. What is the goal, what are the first 5 moves, and one common mistake beginners make?
```
