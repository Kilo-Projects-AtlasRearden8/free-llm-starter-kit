# Welcome to the Free LLM Starter Kit

Run large language models on your own computer. No account, no API key, no credit card, no subscription.

This kit is for beginners. It is written in plain English, step by step, never condescending — like a friend explaining it to you. It is brought to you by **Asdale Dynamics, LLC** (Indiana, formed October 2026).

## What is local AI?

Most AI tools send what you type to a company's computers over the internet. A **local LLM** runs on your own machine instead. Your chats stay on your computer, and you can even turn off the internet and keep chatting.

## Want a static website?

This kit builds into a plain HTML site with no server required:

```bash
python3 scripts/build_site.py
```

Then open `site/index.html` in your browser.
