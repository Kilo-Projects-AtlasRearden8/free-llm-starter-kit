# Free LLM Starter Kit

A free, beginner-friendly kit for running large language models (LLMs)
locally on your own computer. No account, no API key, no cloud required.

Written in plain English, step by step, never condescending — like a
friend explaining it to you. Brought to you by **Asdale Dynamics, LLC**
(Indiana, formed October 2026), beginner-friendly AI education and
practical tools.

## What's inside

| Guide | What it covers |
|-------|---------------|
| [Getting Started](docs/getting-started.md) | What local LLMs are, why privacy matters, what hardware you need |
| [Model Cards](docs/model-cards.md) | Beginner-friendly model recommendations with plain-English specs |
| [Ollama Setup Cheat Sheet](docs/ollama-cheatsheet.md) | Install Ollama, run models, manage models — copy-paste commands |
| [Prompt Starters](docs/prompt-starters.md) | Ready-to-use prompts for writing, learning, admin, and healthcare worker aids |
| [Privacy Basics](docs/privacy-basics.md) | How local-first AI keeps your data on your machine |

## How to use this kit

1. Read [Getting Started](docs/getting-started.md) to pick a model that fits your computer.
2. Follow the [Ollama Setup Cheat Sheet](docs/ollama-cheatsheet.md) to install and run your first model.
3. Copy a prompt from [Prompt Starters](docs/prompt-starters.md) and paste it into your chat.
4. Read [Privacy Basics](docs/privacy-basics.md) to understand what stays on your machine.

## Static site

This kit includes a static HTML site built from the Markdown guides. Run:

```bash
python3 scripts/build_site.py
```

The output goes into `site/`. Open `site/index.html` in your browser. No server, no account, no key needed.
